# tripster_promo_card
HTML/CSS promo card for affiliate advertising

Step by step instructions for implementation on any website:

1. Insert HTML for "promo-card" div in desired position.
2. Add a class for desired promo-card size/border:
	- leave as-is if positioned in full width content (this is 100% responsive and will work on all screen sizes).
	- add "md" class after "promo-card" to position in a medium sized column (8/4 col layout), or to position 2 cards in a row.
	- add "sm" class after "promo-card" to position in a small sized column (sidebar), or to position 3 or 4 cards in a row.
	- add "truncated" class after "promo-card" for compact version, also, add "sm" after "truncated" to position on sidebar.
	- add "border-solid" for solid gray border instead of shadow.
3. Add padding or margin around promo-card as necessary.
4. Test, customize IF necessary, deploy!
5. For usage examples visit https://gattodigital.github.io/tripster_promo_card/ or contact developer contact@gattodigital.com
